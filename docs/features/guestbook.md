# Guestbook

## Goal

Visitors can leave a short message, reply to messages, and like messages/replies. The UI should feel like akryst's small community/guestbook blocks, but with this portfolio's identity.

## V1 Behavior

- Show recent approved messages.
- Show one-level approved replies under a message.
- Allow visitors to like/unlike messages and replies.
- Allow name and message input.
- Allow reply input from the selected message.
- Validate message length.
- Show loading, success, error, and empty states.
- Keep the form usable on mobile.

## Data Model

| Field | Type | Rule |
| --- | --- | --- |
| `id` | string | Generated by service. |
| `name` | string | Required, 2-40 chars. |
| `message` | string | Required, 1-280 chars. |
| `created_at` | string | Service timestamp. |
| `approved` | boolean | Public list only shows approved messages. |
| `like_count` | number | Derived count, not trusted from the client. |

## Reply Model

| Field | Type | Rule |
| --- | --- | --- |
| `id` | string | Generated by service. |
| `message_id` | string | Parent guestbook message. |
| `name` | string | Required, 2-40 chars. |
| `message` | string | Required, 1-220 chars. |
| `created_at` | string | Service timestamp. |
| `approved` | boolean | Public list only shows approved replies. |
| `like_count` | number | Derived count, not trusted from the client. |

## Like Model

| Field | Type | Rule |
| --- | --- | --- |
| `target_type` | string | `message` or `reply`. |
| `target_id` | string | Message or reply id. |
| `visitor_id_hash` | string | Hash of anonymous visitor id. |
| `created_at` | string | Service timestamp. |

## Persistence Plan

Preferred V1: small backend/API with database tables for messages, replies, and likes. Use plain `fetch` from the frontend.

Fallback: hosted guestbook/comment widget only if it supports replies and likes.

Do not store messages only in `localStorage` except as a temporary local demo.

## UI

- Messages are compact glass rows.
- Replies are indented one level under the parent message.
- Likes use a small heart icon/count aligned to the right, like the akryst reference.
- The reply action stays quiet until hover/focus or selected state.
- Name and timestamp use small mono text.
- Message text stays readable, not over-muted.
- Form uses native inputs and textarea.

## Safety

- Escape/render message text as text, not HTML.
- Limit message and reply length.
- Deduplicate likes by anonymous visitor id.
- Rate limit messages, replies, and likes.
- Add moderation before showing untrusted messages publicly.
